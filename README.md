# 中国主动 ETF Dashboard

面向首批主动 ETF 上市前准备的专业研究看板。当前默认使用明确标注的情景模拟数据；产品上市后可切换到统一 API，或直接导入 Excel。

## 已实现

- 市场层：产品数、资产规模、近 20 日净流入、规模加权超额收益
- 产品层：累计收益、业绩基准、年化波动、最大回撤
- 主动管理层：主动份额、跟踪误差、信息比率、集中度
- ETF 交易层：成交额、买卖价差、折溢价、申赎资金流
- 数据治理：数据模式和截止日期常驻展示，模拟数据与真实业绩严格区分
- 数据接入：`GET /api/v1/dashboard` 与 Excel（`funds`、`nav` 工作表）

## 本地运行

需要 Node.js 18+：先运行 `npm install`，然后运行 `npm run dev`。生产构建使用 `npm run build`。API 字段和单位见 [接口契约](docs/API_CONTRACT.md)。复制 `.env.example` 为 `.env.local` 后填写真实服务地址。

## 上市切换清单

1. 以基金合同的业绩比较基准为准，并尽量采用含息/全收益口径。
2. NAV、市场价格、IOPV、PCF、申赎份额分别保留来源时间戳。
3. 不足 60 个交易日时，跟踪误差、信息比率显示“不足样本”，不要外推。
4. 资金流使用份额变化乘以 NAV 的统一算法，并与现金申赎、分红和拆分复核。
5. 日终跑权重合计、净值连续性、代码唯一性、交易日和异常值校验。

本项目是研究与监测工具，不构成投资建议。默认演示数据均为虚构情景数据。
